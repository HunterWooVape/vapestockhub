# 库存录入简表

适用范围：已确认的后台录入工作台。价格和发布由人工把控。

1. **产品资料**：填写品牌、型号和类型，选择推荐标题或自行修改，添加一张产品主图链接。参数有资料再填。
2. **导入清单**：粘贴文字／Excel 表格，或上传／粘贴清单截图。图片在浏览器本机识别；原图由操作人本地保存。
3. **核对明细**：逐项检查口味、规格和数量。修正错字、漏行与未识别内容，再应用。不同版本、浓度和配置分别保留；完全同名且规格相同的行合并。合计以核对后的明细为准。
4. **库存条件**：价格可留空；MOQ 可留空，只有开启公开显示才对外展示。特殊起订区间、混款和箱规写进公开库存说明。最近确认日期只有核实后才填。
5. **预览**：检查电脑／手机布局、明细合计、空项隐藏及价格／MOQ 可见性。联系按钮在预览中不执行跳转。
6. **保存与发布**：未完成的资料先保存草稿；管理员核对必填资料后人工发布。

## 图片核对要点

- 图片识别不代替核对。双语文字、表格线、模糊照片和宣传图可能造成错字或漏行。
- 尽量截取完整库存表，包含表头与数量列，减少周围宣传图。
- 只按清单中的口味与数量录入；示意图上的口味不代表库存。
- 未知数据留空，不补默认 MOQ、日期、参数或价格。
- 原始截图与未整理文字不进入公开详情；系统保存的是应用后的明细和单独填写的公开说明。

真实验证案例与数量仅留在本机私有验收目录；本 SOP 不保存供应商或库存批次原文。后续按实际案例继续修订，流程稳定后再制作 skill。
